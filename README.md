# discodisko.com – studio website

Static site for Disco Disko: studio front page, the Gravel Gas page, its privacy policy and support page, the Hive Tycoon page and privacy policy (all in English and Danish), and `app-ads.txt`.

| Page | Address once live | Used for |
|---|---|---|
| `index.html` | discodisko.com | Developer website in both stores |
| `gravelgas/index.html` | discodisko.com/gravelgas/ | The game page (screenshots, features, store badges) |
| `gravelgas/privacy.html` | discodisko.com/gravelgas/privacy.html | Privacy policy URL (App Store + Google Play), and `PRIVACY_URL` in `grusgas.html` |
| `gravelgas/support.html` | discodisko.com/gravelgas/support.html | Support URL (App Store) |
| `hivetycoon/index.html` | discodisko.com/hivetycoon/ | Hive Tycoon's page (features, screenshots, help in #help) |
| `hivetycoon/privacy.html` | discodisko.com/hivetycoon/privacy.html | Hive Tycoon's privacy policy URL (Google Play). Keep it in step with `site/privacy.html` in the bistaden project |
| `app-ads.txt` | discodisko.com/app-ads.txt | AdMob seller verification (must be at the root) |
| `support/index.html`, `privacy/index.html` | discodisko.com/support/, /privacy/ | Studio-wide pages listing every game; built by `node store/_render/studio-pages.js` (add new games there) |
| `testers/index.html` | discodisko.com/testers/ | "Become a tester" for Google Play closed tests (12 testers for 14 days); built by `studio-pages.js` too |
| `press/index.html` | discodisko.com/press/ | Press kit: facts, descriptions and downloadable assets |
| `404.html` | any missing address | GitHub Pages shows this for unknown addresses |

Shared files: `style.css` (all styling; after changing it or `site.js`, bump the `?v=` number in every page's link so browsers fetch the new file), `site.js` (the English/Danish switch: every page carries both languages, JavaScript shows English unless the address ends in #da, and keeps the choice in the address; without JavaScript both languages show), `logo.svg` (the wordmark as outlines, so no font file is needed), `ball.svg` (the mirror ball, generated by `node store/_render/ball.js`; it is inlined into index.html and 404.html by `node store/_render/stage.js`, which also places the stage lamps and fog, so run both after changing either). `site.js` measures where the lamps' beams point and lights the ball when they hit it. Fonts come from Google Fonts (Fredoka and Nunito). Images in `hivetycoon/` are made from the bistaden project's `store/` graphics (icon 192 px, feature graphic, screenshots at 540×960). Screenshots in `gravelgas/` are 1280 px JPEGs made from `store/screenshots/en/google-play/`; redo them there if the store screenshots change. `gravelgas/flip.mp4` is a 7-second gameplay clip recorded from the real game with `store/_render/video.js` (see store/README.md); it autoplays muted and stays still for visitors who prefer reduced motion. `og.jpg` is the picture shown when the site is shared (1200×630); each game page has its own `og.jpg` made from its feature graphic (scaled to 630 high and centred); it is drawn by opening http://localhost:5180/og.html while `node store/_render/server.js` runs, which saves store/og-image.png (convert to JPEG and copy here). `favicon.svg` is the studio's own icon (a small mirror ball); the PNG sizes next to it and `site.webmanifest` come from http://localhost:5180/favicon.html. `sitemap.xml` and `robots.txt` list every page for search engines; add a line when a page is added. No analytics or tracking, as promised in the privacy policy.

**Music section** (front page, `#music` / `#music-da`): links to the YouTube channels @DiscoDiskoLoFi and @DiscoDisko, the three lo-fi series and a short licence note. Its files are in `music/`: `music.css` (own look like the channel graphics, with Pixelify Sans and IBM Plex Mono served from `fonts/`), `music.js` and pictures made from the channel graphics (`lofi-city.jpg` from the Lo-Fi banner at 1600×900, `lofi.png` and `discodisko.png` from the profile pictures at 160 px). Before the first mix (10 November 2026, 17:00 Danish time) the player box says when it premieres; after that a play button loads the channel's uploads playlist (always newest first) from youtube-nocookie.com. Nothing loads from YouTube until the visitor presses play. Bump `?v=` on the two music links in `index.html` after changing those files.

The "Tell me when it's out" buttons open a ready-made email to contact@discodisko.com. When the store pages exist, replace them with App Store pre-order and Google Play pre-registration links (there is a comment in `gravelgas/index.html` showing where), and swap `avatar.svg` (drawn by `store/_render/avatar.js`, shown with an img tag in `index.html`) for a photo if you like (comment there too).

## Online with GitHub Pages
GitHub Pages is free only for public repositories, and the game repo is private. So the site lives in its own public repo that only contains these files:

- Organization **Disco-Disko**, repo **Disco-Disko/disco-disko.github.io**, live at https://discodisko.com (the old address disco-disko.github.io redirects there)
- Pages serves branch `main`, folder `/ (root)`.

To publish changes after editing files in `site/`, commit them here and run from the project root:

```bash
git subtree push --prefix site site main
```

The remote `site` points to the public repo. If it's missing: `git remote add site https://github.com/Disco-Disko/disco-disko.github.io.git`.

The domain discodisko.com is registered at Cloudflare (bought 4 November 2026, auto-renews). DNS there points the apex to GitHub Pages (four A and four AAAA records, proxy off) and www to disco-disko.github.io; `site/CNAME` holds the domain and HTTPS is enforced in the repo's Pages settings. Mail to contact@discodisko.com is forwarded by Cloudflare Email Routing. If the DNS values ever need re-checking, see GitHub's "Managing a custom domain for your GitHub Pages site".
